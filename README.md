## Por que este projeto

Cada estudo traz o problema, os dados, o método escolhido, o resultado e o que aprendi no caminho — para servir de referência para mim e para quem estiver estudando os mesmos temas.

## O que está a caminho

O projeto está sendo construído em entregas pequenas, cada uma com testes e CI. Acompanhe pelos commits e pull requests.

- [ ] Organização dos trabalhos já feitos
- [ ] Ambiente reproduzível (requirements e instruções)
- [ ] Um resumo por estudo: problema, dados, método e resultado
